    Démarrage

    vst-audit analyse les plugins installés dans /Library/Audio/Plug-Ins et ~/Library/Audio/Plug-Ins (VST2, VST3, AU, CLAP). Aucun plugin n'est chargé ni modifié : seuls les fichiers sur disque sont lus.

    • Actualiser relance l'analyse en direct (non enregistrée, moins d'une seconde).
    • Enregistrer lance une analyse et la garde dans l'historique, pour comparer plus tard.
    • DAW lues : Ableton Live (base de plugins), Logic (validation AU), MPC 3 (liste de plugins scannés, rejetés, désactivés).
    • Cliquez sur une ligne de plugin pour voir tous ses formats, ses remarques et les actions possibles.
    uv run vst-audit web            # cette interface (http://127.0.0.1:8765)
uv run vst-audit scan           # même analyse, dans le terminal
uv run vst-audit uad --suivi    # suivi UADx dans le terminal

    Statuts

    Un plugin présent en plusieurs formats (AU, VST3, VST2) n'occupe qu'une ligne ; son statut est celui de son meilleur format. Les formats cassés sont barrés.

    Actions sur un plugin

    Définir le statut
    Force un statut de licence pour tous les formats du plugin (data/overrides.json), prioritaire sur la détection. « Revenir à l'auto » l'annule.
    Finder
    Sélectionne le bundle dans le Finder.
    Signature
    Vérifie la signature de code (codesign) et affiche le développeur.
    auval
    Lance la validation Apple d'une Audio Unit (peut prendre quelques secondes).
    Sonder ce plugin
    Vérification active : charge le plugin dans un processus séparé, laisse sa vérification de licence aboutir, analyse le son qu'il produit (traité, muet, ou passé tel quel) et, en option, ouvre son interface quelques secondes pour y lire son état (« not activated », « 4 activations left », « TRY UNLICENSED »…). Résultat et capture dans data/sondes.json et data/sondes/. En terminal : vst-audit sonder.
    Lire le journal UA
    UADx uniquement : relit l'état de licence écrit par le plugin.

    Apparence

    Les couleurs reprennent le thème choisi dans Ableton Live (lu dans Preferences.cfg et dans les fichiers .ask de l'application) et la police est Ableton Sans, servie depuis l'application Live installée. Le sélecteur en haut à droite permet d'essayer les autres thèmes de Live.
